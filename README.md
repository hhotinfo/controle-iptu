# Controle de IPTU

Página de controle de IPTU, ITBI e dívida ativa dos imóveis. Publicada pelo GitHub Pages, com os dados guardados no Supabase e acesso só com login.

- `index.html` — o sistema
- `config.js` — endereço e chave pública do projeto Supabase

Os dados dos imóveis **não** ficam neste repositório; ficam no banco do Supabase, protegidos por login.
